# API Design — Информационная система библиотеки

## 1. Общие принципы

- Base URL: `/api/`.
- Формат данных: JSON, Django REST Framework.
- Пагинация: `page` / `limit` (DRF pagination).
- Идентификаторы: целые числа (BigAutoField).

## 2. Аутентификация и права доступа

- Запросы на изменение (POST / PATCH / DELETE) — `IsAuthenticated`
  (роли: читатель, библиотекарь).
- Запросы на чтение каталога / очереди — `AllowAny` для публичного каталога,
  `IsAuthenticated` для личных данных (история выдач).

## 3. Endpoints

### 3.1. Каталог книг

#### GET /api/books/
- **Метод:** GET
- **Назначение:** получение списка книг каталога (поиск / фильтрация).
- **Параметры:** `search`, `author`, `genre`, `publication_year`, `page`.
- **Тело:** —.
- **Ответ:** `200 OK` — `{"count": <int>, "results": [<book>]}`.
- **Ошибки:** `400 Bad Request`.
- **Авторизация:** `AllowAny`.

#### GET /api/books/{id}/
- **Метод:** GET
- **Назначение:** получение книги.
- **Параметры:** path `id`.
- **Тело:** —.
- **Ответ:** `200 OK` — объект книги; `404 Not Found`.
- **Авторизация:** `AllowAny`.

#### POST /api/books/
- **Метод:** POST
- **Назначение:** добавление новой книги в каталог.
- **Параметры:** —.
- **Тело:** `{"title": "...", "description": "...", "isbn": "...", "publication_year": 2020, "publisher": "...", "authors": [1, 2], "genres": [1]}`.
- **Ответ:** `201 Created` — созданная книга; `400`, `409` (ISBN уже существует).
- **Авторизация:** `IsAuthenticated` (библиотекарь).

### 3.2. Физические экземпляры книг

#### GET /api/books/{book_id}/copies/
- **Метод:** GET
- **Назначение:** получение списка экземпляров конкретной книги.
- **Параметры:** path `book_id`.
- **Тело:** —.
- **Ответ:** `200 OK` — список экземпляров (`id`, `book_id`, `inventory_number`, `status`).
- **Ошибки:** `404 Not Found`.
- **Авторизация:** `AllowAny`.

#### POST /api/books/{book_id}/copies/
- **Метод:** POST
- **Назначение:** добавление физического экземпляра книги.
- **Параметры:** path `book_id`.
- **Тело:** `{"inventory_number": "...", "status": "AVAILABLE"}`.
- **Ответ:** `201 Created`; ошибки `400`, `404`, `409` (инвентарный номер занят).
- **Авторизация:** `IsAuthenticated` (библиотекарь).

### 3.3. Читатели

#### POST /api/readers/
- **Метод:** POST
- **Назначение:** регистрация нового читателя.
- **Параметры:** —.
- **Тело:** `{"full_name": "...", "email": "...", "phone": "..."}`.
- **Ответ:** `201 Created`; ошибки `400`, `409` (email уже зарегистрирован).
- **Авторизация:** `IsAuthenticated`.

#### GET /api/readers/{id}/
- **Метод:** GET
- **Назначение:** получение данных читателя.
- **Параметры:** path `id`.
- **Тело:** —.
- **Ответ:** `200 OK`; `404 Not Found`.
- **Авторизация:** `IsAuthenticated`.

### 3.4. Выдача книг

#### POST /api/issues/
- **Метод:** POST
- **Назначение:** выдача экземпляра читателю.
- **Параметры:** —.
- **Тело:** `{"reader_id": <int>, "copy_id": <int>}`.
- **Ответ:** `201 Created` — созданная выдача; `409` при невозможности выдачи.
- **Ошибки:** `400`, `401`, `403`, `404`, `409` (экземпляр не `AVAILABLE`, уже выдан, читатель заблокирован).
- **Авторизация:** `IsAuthenticated`.

### 3.5. Возврат книг

#### POST /api/issues/{id}/return/
- **Метод:** POST
- **Назначение:** возврат выданной книги.
- **Параметры:** path `id`.
- **Тело:** `{"return_date": "2026-11-09T12:00:00Z"}` (необязательно).
- **Ответ:** `200 OK` — обновлённая выдача; `409` если выдача не активна.
- **Ошибки:** `400`, `404`, `409`.
- **Авторизация:** `IsAuthenticated`.

### 3.6. История выдач

#### GET /api/readers/{id}/issues/
- **Метод:** GET
- **Назначение:** получение истории выдач читателя.
- **Параметры:** path `id`.
- **Тело:** —.
- **Ответ:** `200 OK` — `{"count": <int>, "results": [<issue>]}`.
- **Ошибки:** `404 Not Found`.
- **Авторизация:** `IsAuthenticated`.

### 3.7. Очередь ожидания

#### GET /api/books/{book_id}/queue/
- **Метод:** GET
- **Назначение:** получение текущей очереди на книгу.
- **Параметры:** path `book_id`.
- **Тело:** —.
- **Ответ:** `200 OK` — список записей очереди (reader, status, position, expires_at).
- **Ошибки:** `404 Not Found`.
- **Авторизация:** `IsAuthenticated`.

#### POST /api/books/{book_id}/queue/
- **Метод:** POST
- **Назначение:** добавление читателя в конец очереди.
- **Параметры:** path `book_id`.
- **Тело:** `{"reader_id": <int>}`.
- **Ответ:** `201 Created`; `409` (читатель уже в очереди).
- **Ошибки:** `400`, `404`, `409`.
- **Авторизация:** `IsAuthenticated`.

### 3.8. Бронирование / резерв

#### GET /api/reservations/{id}/
- **Метод:** GET
- **Назначение:** получение состояния резерва.
- **Параметры:** path `id`.
- **Тело:** —.
- **Ответ:** `200 OK` — `{"id", "reader_id", "book_id", "status", "queue_date", "expires_at", "position"}`.
- **Ошибки:** `404 Not Found`.
- **Авторизация:** `IsAuthenticated`.

### 3.9. Отмена бронирования

#### POST /api/reservations/{id}/cancel/
- **Метод:** POST
- **Назначение:** отмена бронирования читателем / библиотекарем.
- **Параметры:** path `id`.
- **Тело:** — (или `{"reason": "..."}`).
- **Ответ:** `200 OK` — бронь со статусом `CANCELLED`; `409` если бронь неактивна для отмены.
- **Ошибки:** `400`, `404`, `409`.
- **Авторизация:** `IsAuthenticated`.

### 3.10. Дополнительные endpoint'ы

#### GET /api/books/{book_id}/queue/{reader_id}/position/
- **Метод:** GET
- **Назначение:** получение текущей позиции читателя в очереди на книгу.
- **Параметры:** path `book_id`, path `reader_id`.
- **Тело:** —.
- **Ответ:** `200 OK` — `{"book_id": <int>, "reader_id": <int>, "position": <int>, "status": "<status>"}`; позиция — порядковый номер (1-based).
- **Ошибки:** `404 Not Found`.
- **Авторизация:** `IsAuthenticated`.

## 5. Замечания

- Сложность операций выдачи/возврата рассчитана на транзакционную обработку
  (Django ORM transactions) для консистентности статуса экземпляра.
- Очередь ожидания реализуется через сущность `reservations`
  (см. `docs/DATABASE_DESIGN.md` и `docs/BOOK_QUEUE_DESIGN.md`).

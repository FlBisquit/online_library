# Test Plan — Информационная система библиотеки

## 1. Общие принципы

- Тесты API: Django REST Framework (APITestCase / pytest + APIClient).
- База тестов: SQLite in-memory.
- Фикстуры тестовых данных:
  - Книга: `id=1`, `title`, `isbn`, `publication_year`, `publisher`.
  - Экземпляр: `id=1`, `book_id=1`, `inventory_number`, `status=AVAILABLE`.
  - Читатель: `id=1`, `full_name`, `email`, `status=ACTIVE`.

## 2. Тестовые сценарии

### 1. Работа каталога книг

- **TC-01. Создание книги**
  - *Условия:* библиотекарь авторизован.
  - *Действия:* `POST /api/books/` с данными книги.
  - *Ожидание:* `201 Created`; книга доступна в списке.
  - *Критерий:* статус-код 2xx и запись в БД.

- **TC-02. Получение книги**
  - *Условия:* книга существует.
  - *Действия:* `GET /api/books/{id}/`.
  - *Ожидание:* `200 OK`, корректные поля.
  - *Критерий:* 200 + данные совпадают с БД.

- **TC-03. Список книг**
  - *Условия:* каталог не пуст.
  - *Действия:* `GET /api/books/`.
  - *Ожидание:* `200 OK`, результат содержит книги.
  - *Критерий:* 200 + `results` заполнен.

- **TC-04. Дубликат ISBN**
  - *Условия:* книга с ISBN уже существует.
  - *Действия:* `POST /api/books/` с тем же ISBN.
  - *Ожидание:* `409 Conflict`.
  - *Критерий:* 409.

### 2. Добавление и удаление экземпляров

- **TC-05. Добавление экземпляра**
  - *Условия:* книга существует.
  - *Действия:* `POST /api/books/{book_id}/copies/`.
  - *Ожидание:* `201 Created`, статус `AVAILABLE`.
  - *Критерий:* 201 + экземпляр доступен.

- **TC-06. Дубликат инвентарного номера**
  - *Условия:* экземпляр с номером уже существует.
  - *Действия:* `POST /api/books/{book_id}/copies/` с тем же `inventory_number`.
  - *Ожидание:* `409 Conflict`.
  - *Критерий:* 409.

- **TC-07. Получение экземпляров**
  - *Условия:* экземпляры существуют.
  - *Действия:* `GET /api/books/{book_id}/copies/`.
  - *Ожидание:* `200 OK`, список экземпляров.
  - *Критерий:* 200 + корректный список.

### 3. Регистрация читателей

- **TC-08. Регистрация читателя**
  - *Условия:* —.
  - *Действия:* `POST /api/auth/register/`.
  - *Ожидание:* `201 Created`, статус `ACTIVE`.
  - *Критерий:* 201 + читатель зарегистрирован.

- **TC-09. Дубликат email**
  - *Условия:* читатель с email уже существует.
  - *Действия:* `POST /api/auth/register/` с тем же email.
  - *Ожидание:* `409 Conflict`.
  - *Критерий:* 409.

### 4. Выдача книг

- **TC-10. Успешная выдача**
  - *Условия:* доступен экземпляр `AVAILABLE`, читатель `ACTIVE`.
  - *Действия:* `POST /api/issues/` (`reader_id`, `copy_id`).
  - *Ожидание:* `201 Created`, экземпляр `ISSUED`.
  - *Критерий:* 201 + переход статуса.

- **TC-11. Выдача уже занятого экземпляра** *(негативный)*
  - *Условия:* экземпляр `ISSUED` (уже выдан).
  - *Действия:* `POST /api/issues/` для этого экземпляра.
  - *Ожидание:* `409 Conflict`.
  - *Критерий:* 409 — запрещено выдать двумя читателям.

- **TC-12. Выдача несуществующего экземпляра** *(негативный)*
  - *Условия:* —.
  - *Действия:* `POST /api/issues/` с несуществующим `copy_id`.
  - *Ожидание:* `404 Not Found`.
  - *Критерий:* 404.

- **TC-13. Выдача заблокированного читателя**
  - *Условия:* читатель `BLOCKED`.
  - *Действия:* `POST /api/issues/`.
  - *Ожидание:* `403` / `409`.
  - *Критерий:* операция отклонена.

### 5. Возврат книг

- **TC-14. Успешный возврат**
  - *Условия:* активная выдача `ISSUED`.
  - *Действия:* `POST /api/issues/{id}/return/`.
  - *Ожидание:* `200 OK`, выдача `RETURNED`, экземпляр `AVAILABLE`.
  - *Критерий:* 200 + корректные статусы.

- **TC-15. Возврат неактивной выдачи**
  - *Условия:* выдача уже `RETURNED`.
  - *Действия:* `POST /api/issues/{id}/return/`.
  - *Ожидание:* `409 Conflict`.
  - *Критерий:* 409.

### 6. Продление выдачи

- **TC-16. Продление активной выдачи**
  - *Условия:* активная выдача, продление разрешено.
  - *Действия:* продление `due_at` выдачи.
  - *Ожидание:* `200 OK`, `due_at` обновлён, статус остаётся `ISSUED`.
  - *Критерий:* 200 + срок изменён.

- **TC-17. Продление невозможное**
  - *Условия:* продление не разрешено (лимит / срок истёк).
  - *Действия:* продление.
  - *Ожидание:* ошибка (400/409).
  - *Критерий:* операция отклонена.

### 7. Постановка в очередь ожидания

- **TC-18. Добавление в очередь**
  - *Условия:* нет доступных экземпляров, читатель `ACTIVE`.
  - *Действия:* `POST /api/books/{book_id}/queue/` (`reader_id`).
  - *Ожидание:* `201 Created`, бронь `PENDING`.
  - *Критерий:* 201 + запись в очереди.

- **TC-19. Повторная постановка в одну очередь** *(негативный)*
  - *Условия:* читатель уже в очереди (`PENDING`/`ACTIVE`).
  - *Действия:* повторный `POST /api/books/{book_id}/queue/`.
  - *Ожидание:* `409 Conflict`.
  - *Критерий:* 409.

### 8. Автоматическое резервирование возвращённого экземпляра

- **TC-20. Возврат при непустой очереди**
  - *Условия:* очередь не пуста.
  - *Действия:* возврат экземпляра (`ISSUED → AVAILABLE`) + обработка очереди.
  - *Ожидание:* первый в очереди → бронь `ACTIVE`, экземпляр `RESERVED`, `expires_at = now + 48h`.
  - *Критерий:* продвижение корректно.

- **TC-21. Возврат при пустой очереди**
  - *Условия:* очередь пуста.
  - *Действия:* возврат.
  - *Ожидание:* экземпляр `AVAILABLE`, очередь пуста.
  - *Критерий:* 200 + доступность.

### 9. Отмена бронирования

- **TC-22. Отмена бронирования**
  - *Условия:* бронь `PENDING` / `ACTIVE`.
  - *Действия:* `POST /api/reservations/{id}/cancel/`.
  - *Ожидание:* `200 OK`, бронь `CANCELLED`, продвижение очереди.
  - *Критерий:* 200 + очистка.

- **TC-23. Отмена чужого бронирования** *(негативный)*
  - *Условия:* бронь принадлежит другому читателю.
  - *Действия:* попытка отменить.
  - *Ожидание:* `403` / `404`.
  - *Критерий:* отмена невозможна.

### 10. Истечение срока резерва

- **TC-24. Истечение срока резерва**
  - *Условия:* бронь `ACTIVE`, `now > expires_at`.
  - *Действия:* обработка истечения.
  - *Ожидание:* бронь → `EXPIRED`, экземпляр → `AVAILABLE`, продвижение очереди.
  - *Критерий:* корректный переход.

## 3. Итоговый структурированный список тестовых сценариев

1. TC-01 … TC-04 — каталог книг.
2. TC-05 … TC-07 — добавление/получение экземпляров.
3. TC-08 … TC-09 — регистрация читателей.
4. TC-10 … TC-13 — выдача книг (включая негативные).
5. TC-14 … TC-15 — возврат книг.
6. TC-16 … TC-17 — продление выдачи.
7. TC-18 … TC-19 — постановка в очередь (включая негативный).
8. TC-20 … TC-21 — автоматическое резервирование.
9. TC-22 … TC-23 — отмена бронирования (включая негативный).
10. TC-24 — истечение срока резерва.

**Обязательные негативные тесты** (все покрыты): TC-04, TC-11, TC-12, TC-13, TC-19, TC-23, TC-24 (по смыслу), а также
- «Попытка выдать зарезервированный экземпляр другому читателю» — см. TC-11 (резерв ↔ выдача).
- «Одновременные запросы на последний свободный экземпляр» — отдельный race-тест:
  - *Условия:* один экземпляр `AVAILABLE`.
  - *Действия:* два параллельных `POST /api/issues/`.
  - *Ожидание:* один `201`, второй `409`; экземпляр `ISSUED`.
  - *Критерий:* ровно один успешный выдача.
